# Paper Clock screenshots

## Play Store

`screenshots/play-store/` contains six RGB PNGs at **1080 × 1920 (9:16)**, ready to upload:

1. `next-alarm.png` — alarm overview
2. `goals-progress.png` — linked goal and countdown
3. `goal-builder.png` — four-step goal flow
4. `wake-up-sounds.png` — bundled sound picker
5. `alarm-editor.png` — repeat, goal, sound, and vibration controls
6. `alarm-time-picker.png` — time selection

The captures were taken on a Pixel 10. Native 20:9 screenshots were scaled and centered on the app's near-black background so no UI is cropped.
